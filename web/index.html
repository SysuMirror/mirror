YatSSO 生态

一个账号，接入整个生态

这些应用都通过 YatSSO 完成单点登录；每次授权都出同意页，只交出被明确同意的字段。身份只回答「你是谁」，权限由各平台自行判定。

技术底座

一套底座，支撑全部子平台

软工集市作为技术验证载体，沉淀出统一鉴权、部署调度与算力供给的基础设施，支撑全部子平台运行，也是对外输出技术能力的来源。

YatSSO

一次登录，处处通行

标准 OAuth2 授权码 + PKCE(S256)；OIDC ID Token 用 RS256 签名，公钥通过 JWKS 公开，可离线验签。

DEPLOY

部署调度中枢

自研 Deploy 体系覆盖从代码到上线的全流程，子平台按需部署、灰度发布。

YatTerra

把算力接进同一层

连接校园与实验室的内网 GPU，统一编排 Pod、GPU、存储；vLLM / LoRA 推理与 Telemetry 观测走同一套平台。

身份只回答「你是谁」，权限由各平台自行判定；每次授权都出同意页，字段按 scope 最小化，跨服务关联同一人的 sse_sub 需单独申请 sse_identity。

服务

把底座能力交给场景

无论是学生场景的数据可视化与平台工具，还是院系部门、校企合作单位的数字化系统，团队具备从需求分析、架构设计到系统交付的完整工程实践能力。

01

数据可视化与平台服务
